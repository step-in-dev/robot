# Редактор обстановок Робота

Редактор обстановок — отдельное настольное приложение для создания и редактирования файлов задач `.env`.

## Запуск

```bash
python editor/editor.py
```

Редактор открывается с новой пустой обстановкой (поле 5×5, старт робота в левом верхнем углу, финиш в правом нижнем). Чтобы открыть существующий файл задачи или сохранить работу, используйте меню **Файл**.

## Возможности

- Редактирование стен, закрашенных клеток, клеток для закраски, загрязнений и чисел для печати кликом по полю.
- Переключение между несколькими обстановками в одном файле задачи.
- Изменение размера поля, сброс текущей обстановки, добавление и удаление обстановок.
- Редактирование условия задачи (`todoText`), отображаемого над полем.
- Отмена и повтор последних действий (меню **Правка** или кнопки на панели инструментов).
- Открытие, сохранение и «Сохранить как» через меню **Файл**.
- Размер поля ограничен 10 столбцами на 8 строк; в одном файле задачи может быть до 7 обстановок.
- При сохранении поверх встроенной задачи из `robot/tasks/` редактор запрашивает подтверждение (и для **Сохранить**, и для **Сохранить как**).

При загрузке и сохранении редактор сохраняет поля ограничений решения верхнего уровня (`operatorsLimit`, `customFunctionCallCount`, `ifLimit`, `whileLimit`, `requiredKeywords`, `bannedKeywords`), но не предоставляет интерфейса для их редактирования.

## Горячие клавиши

- `Ctrl+O` — открыть
- `Ctrl+S` — сохранить
- `Ctrl+Shift+S` — сохранить как
- `Ctrl+Z` — отменить
- `Ctrl+Y` — повторить

## Иконки панели инструментов

PNG-иконки панели лежат в `robot/assets/editor_icons/` (исходники в `svg/`, растр 24×24 в `png/`). Состав набора и команда пересборки — в [`robot/assets/editor_icons/SPEC.md`](../robot/assets/editor_icons/SPEC.md) (`python tools/build_editor_icons.py`). Загрузка для Tkinter — в `robot/editor_icons.py`.

## Формат файла

Сохранённые файлы используют тот же JSON-формат `.env`, что и встроенные задачи Робота. См. [task-env-format.ru.md](task-env-format.ru.md).
