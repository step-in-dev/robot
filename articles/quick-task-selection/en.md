# How to quickly choose Robot tasks for a lesson: the online catalog and the task viewer

For previewing tasks there is the online catalog on the website and the local task viewer in the module. Both show the same thing:

- the task text;
- the topic and task number;
- all environments for the task;
- solution limits, when the task has them.

## The online task catalog

Available at [robot.stepindev.com/tasks/index.html](https://robot.stepindev.com/tasks/index.html). It contains the task set from the latest version of the module, grouped by topic. Handy when you want to browse tasks at home, on a school computer, or send a link to a colleague without installing Robot.

![A task page in the online catalog with the topic, number, environment, and limits visible.](../../website/img/task_catalog/task_en.webp)

## The task viewer in the module

Runs locally through `viewer/viewer.py`. No internet required: in a classroom with no network you can still open topics, switch between tasks, and show them on a projector. More importantly, it shows the tasks from the exact version of the module installed on that computer, the same set students will actually open.
